# 🎮 Video Game Sales Analysis

A data analysis project exploring video game sales trends, top publishers, and genre performance using Python and Jupyter Notebook.

## 📊 Project Overview

This project analyzes a video game sales dataset from Kaggle to uncover patterns in the gaming industry. The analysis focuses on:

- Which publishers generate the highest global sales
- Best-performing genres across different regions (North America, Europe, Japan)
- Sales trends over time
- Most successful gaming platforms

## 📁 Files

| File | Description |
|------|-------------|
| `VideoGamesSales` | Raw dataset from Kaggle (Excel format) |
| `VideoGamesYoutubeProject` | Jupyter notebook containing all analysis code |

## 🛠️ Tools Used

- **Python** - Core programming language
- **Pandas** - Data cleaning and manipulation
- **Matplotlib / Seaborn** - Data visualization
- **Jupyter Notebook** - Interactive analysis environment
